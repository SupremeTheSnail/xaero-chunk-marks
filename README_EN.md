A client-side add-on for Xaero's World Map. It adds a "mark chunk" entry to the map's right-click menu; marked chunks
are drawn as translucent overlays on the map.

Marks are stored in a local config file only. The mod sends no packets, claims no chunks and force-loads no chunks.

## Requirements

| Dependency | Version |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.x |
| Xaero's World Map | 1.39 or newer |

## Installation

1. Install Forge 1.20.1.
2. Put Xaero's World Map into `mods/`.
3. Put `xaerochunkmark-1.0.0.jar` into `mods/`.

Download: [Releases](https://github.com/SupremeTheSnail/xaero-chunk-marks/releases) ·
[direct link](https://github.com/SupremeTheSnail/xaero-chunk-marks/releases/download/v1.0.0/xaerochunkmark-1.0.0.jar)

## Usage

- Right-click a chunk on the world map. The menu shows "Mark Chunk (x, z)".
- Hold right-click and drag to select multiple chunks; the menu shows "Mark N Chunks".
- Right-click a marked chunk. The menu shows "Unmark Chunk".
- Hovering a marked chunk shows "Marked chunk (x, z)".

## Configuration

The config file is `config/xaerochunkmark-client.toml`:

| Key | Default | Description |
| --- | --- | --- |
| `appearance.color` | `FF9D2E` | Mark colour, RRGGBB |
| `appearance.fillOpacity` | `60` | Opacity of the chunk interior, 0–255 |
| `appearance.borderOpacity` | `220` | Opacity of the outline next to unmarked chunks, 0–255 |

The map repaints automatically after a change.

## Storage

```
config/xaerochunkmark/<world id>-<hash>.json
```

One file per world, one entry per dimension:

```json
{
  "format": 1,
  "world": "Multiplayer_play.example.com|",
  "dimensions": {
    "minecraft:overworld": [[0, 0], [0, 1], [1, 1]]
  }
}
```

Deleting a file clears the marks of that world.

## Implementation

- Chunk tinting uses Xaero's `ChunkHighlighter` API with `coveringOutsideDiscovered = true`.
- The highlighter is registered reflectively with `MapProcessor#getHighlighterRegistry()` on `ClientTickEvent`.
- After a mark changes, `clearCachedHash()` is called so the affected regions rebuild their highlight texture.
- The menu entry is injected into `GuiMap#getRightClickOptions()` with Mixin; chunk coordinates and the selection are
  read from private `GuiMap` fields.

The mod contains no packet handling and no `setChunkForced` calls.

## Building

Requires JDK 17 and network access.

```bash
./gradlew build
```

The jar is written to `build/libs/xaerochunkmark-1.0.0.jar`.

The repository does not contain Xaero's jars. Follow [libs/README.md](libs/README.md) to put Xaero's World Map and
XaeroLib into `libs/` before building. The GitHub Actions workflow does this automatically.

## Compatibility

- The injection target `GuiMap#getRightClickOptions()Ljava/util/ArrayList;` exists in 1.39.12 and 1.47.0.
- `injectors.defaultRequire = 0` in `mixins.json`: a failed injection is logged, the menu entry is hidden, the game
  does not crash.
- If a reflected field is missing, the menu entry is disabled and the reason is logged.
- Only the world map is affected; the Xaero minimap is not.

## Known limitations

- Chunks with no map data are tinted only after that area has map data.
- Marks are stored in `config/`, so clearing the map cache keeps them; deleting that directory removes them.
